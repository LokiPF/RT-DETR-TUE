## Pipeline

Points 0.1, 0.2, 0.3, and 0.4 are necessary for epistemic uncertainty. 0.5 and 0.6 are necessary for aleatoric uncertainty. The confidence is calibrated while the bbox gives an uncertainty.

0.1 Build TU Prototypes --> Use train split to create the Fréchet mean. The saved .pth file contains the Fréchet mean per class and size, per class, and global (as a fallback if not enough detections given the IoU filter where generated by the training set)

0.2 Calibrate CP --> Use a seperate calibration split to calculate qhat, which is required for uncertainty bbox
